The JSDoc says what the code does in four places. `destroy` of a display object ends the asset when that object was its last holder. `stop` with a mix returns the track to what lower tracks give, or to the setup pose. `StopOptions.mix` says the same. `autoUpdate` says that a hidden object with a mix or several tracks is still posed, and that no vertex is placed.
