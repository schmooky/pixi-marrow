This guide shows how to load, play and control Spine animations in PixiJS with pixi-marrow, one step at a time. You need no experience with Spine. If pixels, transforms, triangles and draw calls are new to you, read the [Basics](/basics/pixels/) first: five short pages with animations. Its examples use the symbols of the slot game Bzzz, which ship with this site, so many of them look like slot symbols. Nothing in the guide is specific to slots.

## What Spine is

There are two ways to animate a 2D character. Watch the same wave made both ways:

<Diagram name="skeletal" height={300} rows={2} caption="Left, a wave from a sprite sheet of 8 pictures, shown one after the other. Right, the same wave from a skeleton: 2 pictures and a bone that turns the arm." />

**Frame by frame**, an artist draws every picture of the motion, and the game shows them one after the other. The left side has 8 pictures, and the arm jumps from one to the next. More smoothness means more pictures, and more pictures mean more memory and longer loading.

**Skeletal animation**, which Spine does, splits the character into parts: a body, an arm. A bone holds each part, and the animation stores only a few numbers per bone, such as "the arm turns from -35 to 55 degrees". In every frame the runtime computes where each bone is and draws the parts there. So the motion is smooth at any frame rate, the files stay small, and two animations can blend into each other, which pictures cannot.

## What a runtime does

The Spine editor exports three kinds of files:

- A skeleton file, `.skel` or `.json`, with the bones, the parts and the animations, all as numbers.
- An atlas file, `.atlas`, that says where each part lies in the images.
- The images, such as `.png`, `.webp` or `.avif`, with all parts packed into one or a few pages.

A runtime reads these files and does the work in every frame. It finds the pose of each bone at the current time, places the parts, and has the GPU draw them. pixi-marrow is a runtime for PixiJS v8. [One frame](/how/frame/) shows the whole way from the time to the pixels.

## Install

```bash
npm install pixi-marrow@next pixi.js
```

`pixi.js` is the one peer dependency, from version 8.21. The package is a pre-release, on the `next` tag of npm.

`skeleton` is a `.skel` or `.json` export of Spine 4.1, 4.2 or 4.3. The page images load from next to the atlas.

`hero` is a Pixi `Container`. Move it, scale it and add it to the stage like any other.

## Play

<Snippet source={source} regions="play" />

`play` starts an animation now. `loop: true` repeats it until something else plays. A name the skeleton lacks throws a `MarrowError` that lists the valid names.
