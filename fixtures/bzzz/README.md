# Bzzz symbol rigs

The symbols of the slot game Bzzz: 16 skeletons of Spine 4.2.43 in the binary format, one atlas and its page image. They are in this repository with the leave of the owner of the game, for the tests and for the docs site.

They are the first rigs of a real game the runtime was run on. The parity suite runs on them as on the official examples, and the docs site shows the bee.
